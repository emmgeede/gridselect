GridSelect

Playground for every list,
short or long

Every variant of GridSelect in one place: native radios and checkboxes, the search panel in both modes, selects, forms and digit shortcuts. The page loads src/gridselect.js and src/gridselect.css directly, so it always shows the current state.

JS · items

Entries from JavaScript

An empty wrapper plus items: GridSelect builds the radios. setItems() swaps the entries, keeps the choice where it still exists and switches between visible items and the panel.

Element · grid-select

Custom element

<grid-select> builds everything from its <option> children, no JavaScript call needed. Attributes and options can change at any time.

Layout · flow

Flow layout

data-layout="flow": items run one after another like the chips, as dense as possible. Arrow up/down jump to the nearest item in the row above or below.
