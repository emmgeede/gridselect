GridSelect

A dependency-free select for any list length. Short lists stay visible, long ones open a searchable grid. Native inputs underneath, full keyboard support, digit shortcuts, light and dark mode.

Source and documentation on GitHub

Short list

Up to 10 entries the radios stay visible. Arrow keys move, digits pick directly.

Shipping
<fieldset data-gridselect>
  <legend>Shipping</legend>
  <label><input type="radio" name="ship" value="std" checked> Standard</label>
  …
</fieldset>

gridselect(document.querySelector("[data-gridselect]"));

Multiple choice

Checkbox groups work the same way. Space or a digit toggles.

Extras

Long list with filter

More than 10 entries: a compact field opens a panel. Type to filter (try dollar or zur), arrows move through the grid, Enter or a digit picks.

Long list with highlight

Items never move, matches are marked. Good for lists people use every day.

<fieldset data-gridselect data-search="highlight"> … </fieldset>
